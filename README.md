## 📌 Project Overview

ArthaBank is a mid-sized bank digitizing its manual loan process. 
This portfolio documents the complete BA lifecycle — from business 
case to UAT — for a Digital Loan Processing System covering 
Vehicle, Education, and Personal Loan modules.

**Problem:** Customers had to visit the branch physically to apply 
for loans, causing delays, errors, and poor experience.

**Solution:** An end-to-end digital loan platform enabling online 
applications, document uploads, real-time status tracking, and 
officer approval dashboards.
